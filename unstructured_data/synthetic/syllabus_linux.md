  Course Outcomes: After completing the course, the students will be able to:
 CO1: Explain the fundamental concepts of Linux Operating system, kernel space with related data
   structure and implementation
 CO2: Analyze Linux process management, memory management, scheduling and Inter process com-
   munication mechanism.
 CO3: Apply concepts of Linux user space and kernel space concepts to understand system level
   operations, synchronization and optimization.
 CO4: Design and Implement system level programs and drivers using Linux kernel concepts
 CO5: Develop and evaluate project involving Linux kernel concepts for customization, monitoring or
   performance tuning for real-world applications
