 offs:Sorting by Counting, Input Enhancement in String Matching: Horspools and Boyer-Moore al-
 gorithm.

 Dynamic Programming: Computing a Binomial Coefficient, Warshalls and Floyds Algorithms,
 0/1 Knapsack Problem and Memory Functions.Greedy Technique: Prims Algorithm, Kruskal’s
 Algorithm, Dijkstras Algorithm, Huffman Trees and codes, Fractional Knapsack Problem.
                                 Unit - V                                            7    Hours
 Backtracking: N-Queens Problem, Sum of Subset Problem.Branch-and-Bound: Travelling Sales-
 person Problem, Assignment Problem Decision Trees: Decision Trees for Sorting NP and NP-
 Complete Problems: Basic Concepts, Non- Deterministic Algorithms, P, NP, NP Complete, and
 NP-Hard classes
 Part A- Practice Programs- Implementation and execution of simple programs to un-
 derstand running time analysis of non-recursive and recursive algorithms

     Naive string matching algorithm

     Find the Factorial of a given number

     Print Fibonacci series

     Given a positive decimal integer n, find the number of binary digits in n bit binary representation

     To solve tower of Hanoi problem.

     Recursive linear search
 Lab Programs
  2. Design and Implement at-least one application from each of the following group

    1. Apply divide and conquer strategy to solve sorting problem (Merge sort, Quicksort)
    2. Apply decrease and conquer strategy to solve graph problem (Breadth first search, Topological
       sorting using depth first search)
    3. Apply transform and conquer strategy (Heapsort, Checking element uniqueness after presort-
       ing)

    4. Apply input enhancement strategy to solve string-matching problem (Horspools algo-
       rithm,Boyer – Moores algorithm)
    5. Apply dynamic programming strategy to solve optimization problem(Warshall - Floyds Algo-
       rithms, Knapsack problem solution using memory function.)

    6. Apply greedy strategy to solve graph problem(Dijkstras algorithm,Prims algorithm,Kruskals
       Algorithm)
    7. Apply backtracking strategy to solve combinatorial problem(N- Queen’s problem,Subset – sum
       problem)

    8. Apply branch and bound strategy to solve combinatorial problem(Travelling salesperson prob-
       lem, Assignment problem)
  3. Part B- Experiential Learning: Students are required to design and implement a project that
     applies appropriate algorithmic techniques to solve a real-world problem. The project should
     involve problem formulation, selection and design of suitable algorithms, and analysis of their time
     and space complexity. The project should demonstrate the practical application of concepts such
     as divide and conquer, greedy methods, dynamic programming, backtracking, graph algorithms,
     or other relevant algorithmic techniques.
  Course Outcomes: After completing the course, the students will be able to:
 CO1: Apply mathematical foundations and computational principles to solve problems.
 CO2: Analyze problem statement and select appropriate algorithmic paradigms and data structures
   to find solution.
 CO3: Design efficient algorithms considering correctness, complexity, and trade-offs.
 CO4: Develop software solutions using appropriate algorithms and programming tools.
