## Course CS301 - Database Management Systems (4 credits)

### Course Outcomes
- CO1: Design entity-relationship models for a given application.
- CO2: Write SQL queries for data definition, manipulation and retrieval.
- CO3: Apply normalization to improve a relational schema.
- CO4: Explain transaction processing, concurrency control and recovery.

### CO-PO mapping matrix
| CO  | PO1 | PO2 | PO3 | PO5 |
|-----|-----|-----|-----|-----|
| CO1 | 2   | 2   | 3   | -   |
| CO2 | 3   | 2   | -   | 3   |
| CO3 | 3   | 3   | 2   | -   |
| CO4 | 2   | -   | -   | 1   |

PO1 = Engineering knowledge, PO2 = Problem analysis, PO3 = Design/development of solutions, PO5 = Modern tool usage.

### Attainment method (CS301)
- Target: 60% of students must score at least 60% of the maximum marks in the questions mapped to a CO.
- Attainment level 3 if 70% or more of students meet the target; level 2 if 60% to under 70%; level 1 if 50% to under 60%; level 0 below 50%.
- Final CO attainment = 80% weight on direct assessment (CIE + SEE) and 20% weight on indirect assessment (course exit survey).
