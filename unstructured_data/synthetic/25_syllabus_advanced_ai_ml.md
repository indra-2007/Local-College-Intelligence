 LABORATORY COMPONENT
 The laboratory is designed as a problem-driven mini-project based lab where students progressively
 build an intelligent learning system by integrating AI reasoning and machine learning techniques
 instead of isolated experiments. Students will implement algorithms using Python (NumPy, Scikit-
 learn or equivalent open-source tools).
 PHASE – I: Intelligent Problem Solving (AI Component)
 Students shall implement and analyze at least TWO of the following:
  1. Heuristic search (A∗ , Greedy Best First Search).
  2. Constraint Satisfaction Problem solver (Map coloring / Sudoku).
  3. Game playing agent using Minimax with Alpha-Beta pruning.
  4. Logical inference using propositional logic/rule-based system.
 Outcome: Model an intelligent agent and evaluate solution optimality.
 PHASE – II: Predictive Machine Learning Models
 Students shall implement and compare at least THREE models:
  5. Regression model (Linear / Logistic).
  6. Support Vector Machine (with different kernels).
  7. k-Nearest Neighbor classifier.
  8. Ensemble method (Random Forest / Boosting).
 Outcome: Build predictive models and compare performance metrics.
 PHASE – III: Pattern Discovery
 Students shall perform unsupervised learning on a real dataset:
  9. K-means/Hierarchical clustering comparison.
 10. Cluster validation analysis.
 11. Association rule mining (Apriori).
 Outcome: Discover hidden patterns and interpret knowledge.
 PHASE – IV: Advanced Learning Paradigms (Mini Project)
 Students must develop a complete intelligent ML application involving feature representation, model
 selection, performance comparison, and interpretation of results.
 Example domains (any one): Medical diagnosis prediction, Network intrusion detection, Recommen-
 dation system, Fraud detection, Game strategy analyzer, Student performance prediction.
 Outcome: Design an end-to-end intelligent system.
