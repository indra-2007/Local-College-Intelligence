                                    Unit - I                                             9   Hours
 Introduction: Abstract Data Types (ADT), Primitive and Non-primitive Data Types, Linear and
 Non-linear Data Structures. Static and Dynamic Memory Allocation.
 Linked Lists: Singly, Doubly, Circular, Operations on Linked Lists: Creation, Insertion, Deletion,
 Traversal, Searching, Applications of Linked Lists. Self-learning / Extended Topics:Multi-level
 or hierarchical linked lists, Polynomial representation and arithmetic using linked lists, Sparse matrix
 representation, Circular linked lists for round-robin scheduling, Managing dynamic collections (train
 composition, student records, inventory), Merging and splitting linked lists, Reverse a linked list
 (iterative and recursive approaches)
                                    Unit - II                                            9   Hours
 Stacks: LIFO concept, abstract data type, Stack operations: push, pop, peek, Implementation using
 arrays and linked lists. Applications: Expression evaluation and conversion, Parenthesis balancing,
 Tower of Hanoi
 Self-learning / Extended Topics:Using stacks to eliminate recursion (iterative problem-solving),
 Implementing multiple stacks in a single array, Undo/Redo operations in text editors, Backtrack-
 ing problems (maze solving, N-Queens problem), Implementing custom stack variations (Min/Max
 Stack, Stack of Plates), Simulating browser history navigation, Stock Span Problem, Reverse a Stack
 Without Extra Space, Balanced parentheses checking, Largest Rectangle in Histogram
                                   Unit - III                                            9   Hours
 Queues: FIFO concept, abstract data type, Queue operations: enqueue, dequeue, front, rear. Types:
 Simple, Circular, Double-Ended, Priority Queues. Implementation using arrays and linked lists.
 Applications: Scheduling, buffering, simulation problems
 Self-learning / Extended Topics:Implementing multiple queues in a single array, Circular queue
 operations and efficiency analysis, Double-ended queues (Deque) and applications, Custom queue
 applications (printer/job scheduling, CPU task buffering, Josephus problem, round-robin scheduling).
 Combining stack and queue operations for complex problems, BFS in graphs using queue
                                   Unit - IV                                             9   Hours
 Trees: N-ary Trees, Binary Trees, Binary Search Trees, Expression Trees, Forests. Properties and
 conversion of N-ary tree / Forest to Binary tree. Traversals: Preorder, Inorder, Postorder. Binary
 Search Tree operations: Creation, Insertion, Deletion, Display. Threaded Binary Tree.
 Self-learning / Extended Topics: Constructing and evaluating expression trees (arith-
 metic/boolean), Level-order traversal using queues, Finding height/depth, leaf nodes, internal nodes,
 and node count (recursive and iterative), Lowest Common Ancestor (LCA) problems, Advanced
 traversal techniques: Morris Traversal (Inorder without recursion/stack), Designing custom trees for
 real-world hierarchical data (file systems, organizational charts), Expression tree evaluation
                                    Unit - V                                             9   Hours

2. Lab Programs:(At-least two applications from each of the data structures basket)
     Application of List

          – Implementation of sparse matrix multiplication.
          – Implementation of polynomials operations (addition, subtraction) using Linked List.
          – Merge two sorted linked lists.
          – Implementation of Josephus problem using circular linked list.
          – Detect and remove loops in linked lists.

     Application of Stack

          – Implementation of Infix to Postfix conversion
          – Implementation of Infix to Prefix conversion
          – Implementation of evaluation of postfix expression
          – Implementation of evaluation of prefix evaluation
          – Iterative Tower of Hanoi using stack

     Application of Queue

          – Implement Circular Buffer or Ring Buffer
          – Implement Priority Queue to Add and Delete Elements
          – Implementation of Double Ended Queue
          – Implementation of maze problem
          – CPU Round-Robin scheduling simulation

     Application of Trees

          – Implementation of Binary tree and perform level-order traversal using a queue.
          – Implementation of Expression Tree.
          – Implementation of a decision tree for a simple classification problem.
          – Implementation of Binary Search Tree based dictionary
          – Implementation of Threaded Binary Tree (Left-in / Right-in / Double threaded).

     Application of Advanced trees and Hash Table

          – Implementation of Double hashing technique
          – Implementation of AVL tree.
          – Implementation of priority queue using Binary Heap.
          – Implementation of Graph using adjacency matrix and check if it is connected graph.
          – Implementation of dictionary using Trie
          – Implementation of B tree.

 Part B
  3. Experiential Learning:Students are encouraged to implement an advanced data structure not

     its application
